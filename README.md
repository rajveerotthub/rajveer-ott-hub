# RAJVEER OTT HUB — Free Static Website

## Free hosting
1. Create/sign in to a GitHub account.
2. Create a **public** repository named `rajveer-ott-hub`.
3. Upload `index.html` and `style.css` (and the `images` folder if you add images).
4. Open **Settings → Pages**.
5. Under Build and deployment, select **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then Save.
7. GitHub will provide your free Pages URL.

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html`.
- Replace `YOURNUMBER` in the WhatsApp link with your business WhatsApp number in international format.
- Add your actual payment method only after confirming the payment provider's business/reseller requirements.
- Verify that every subscription you sell is authorized for resale/distribution and that your offers comply with the relevant provider terms.
